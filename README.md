
# ☕ Java Fundamentals

Repositório dedicado ao registro da minha evolução nos fundamentos da linguagem Java, reunindo exercícios práticos desenvolvidos durante meus estudos.

Os exercícios estão organizados por tópico, acompanhando minha progressão desde os conceitos básicos da linguagem até a utilização de estruturas condicionais e laços de repetição.

## 📚 Conteúdos estudados

| Etapa | Tópico | Exercício | Conceitos praticados |

| 02 | Entrada de dados e operações | [PartsSales](02-input-and-operations/PartsSales.java) | Entrada de dados com `Scanner`, operações aritméticas e cálculo do valor total de peças |

| 05 | `switch/case` | [WeekdayIdentifier](05-switch-case/WeekdayIdentifier.java) | Estrutura `switch`, `case`, `break` e `default` |
| 06 | Laço `while` | [KeyCheckWh](06-while/KeyCheckWh.java) | Repetição condicionada à validação de uma senha |
| 06 | Laço `while` | [ProductsWh](06-while/ProductsWh.java) | Contadores, estruturas condicionais e controle de repetição |
| 06 | Laço `while` | [QuadranteWh](06-while/QuadranteWh.java) | Operadores lógicos e identificação de quadrantes cartesianos |
| 07 | Laço `for` | [OddNumbersFor](07-for/OddNumbersFor.java) | Iteração, números ímpares e operador módulo `%` |

## ▶️ Como executar

### Pré-requisitos

É necessário possuir o **JDK (Java Development Kit)** instalado e configurado.

### 1. Clonar o repositório

```bash
git clone https://github.com/ArthurMSousa/java-fundamentals.git
```

### 2. Acessar a pasta de um exercício

Por exemplo, para executar o programa de cálculo de conta telefônica:

```bash
cd java-fundamentals/03-if-else
```

### 3. Compilar o código

```bash
javac BillAmount.java
```

### 4. Executar o programa

```bash
java BillAmount
```

### Exemplo de execução

```text
Digite a quantidade de minutos utilizada:
120
Valor da conta = R$ 90,00
```

Para executar os demais exercícios, basta acessar a pasta correspondente, compilar o arquivo `.java` e executar a classe desejada.
