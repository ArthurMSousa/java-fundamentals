# Java Fundamentals

Repositório criado para documentar minha evolução nos fundamentos da linguagem Java, através de exercícios práticos organizados por tópico.

## Conteúdos estudados

| # | Tópico | Exercício | Descrição |
|---|--------|-----------|-----------|
| 01 | Fundamentos da linguagem | `ItemList` | Tipos primitivos, formatação de saída com `printf` e uso de `Locale` |
| 02 | Entrada de dados e operações | `PartsSales` | Cálculo do valor total de uma venda a partir de código, quantidade e preço de peças |
| 03 | Estruturas condicionais (if/else) | `BillAmount` | Cálculo de conta telefônica com cobrança extra por minuto excedente |
| 04 | Operador ternário | `Discount` | Cálculo de desconto de um produto usando expressão condicional |
| 05 | switch/case | `WeekdayIdentifier` | Identificação do dia da semana a partir de um número |
| 06 | while | `KeyCheckWh` | Validação de senha em loop até o acerto |
| | | `ProductsWh` | Contagem de produtos vendidos por tipo (álcool, gasolina, diesel) |
| | | `QuadranteWh` | Identificação do quadrante de um par de coordenadas (x, y) |
| 07 | for | `OddNumbersFor` | Listagem dos números ímpares até um valor informado |
| | | `DivFor` | Listagem dos divisores de um número informado |
| 08 | do/while | `TempDoWhile` | Conversão de temperatura Celsius → Fahrenheit, repetindo enquanto o usuário desejar |
